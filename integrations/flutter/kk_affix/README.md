# kk_affix: казахские окончания для подставляемых значений

Проблема из ТЗ (`suffix_harmony`): в строке `"{name}-ға жіберілді"` окончание выбрано заранее,
а имя игрока подставляется во время игры. Для «Айдос» нужно `-қа`, для «Айгерім» `-ге`,
для «100» `-ге`, для «6» `-ға`. Любое заранее выбранное окончание ошибочно примерно для половины значений.

Пакет выбирает окончание по самому значению: по гармонии гласных и по последнему звуку.
Числа читаются словами (5 → бес → `5-тен`), латиница — по звучанию (`Google` → гугл → `Google-ға`).

```dart
import 'package:kk_affix/kk_affix.dart';

kkInflect('Айдос', KkCase.dative);        // Айдосқа
kkInflect('Әлия', KkCase.dative);         // Әлияға
kkInflect('Ерлан', KkCase.instrumental);  // Ерланмен
kkInflect('5', KkCase.ablative);          // 5-тен
kkInflect('100', KkCase.dative);          // 100-ге
kkInflect('Google', KkCase.dative);       // Google-ға
kkAffix('Серік', KkCase.ablative);        // тен
```

Падежи: `dative` (-ға/-ге/-қа/-ке), `locative` (-да/-де/-та/-те), `ablative` (-дан/-нан/-тан…),
`genitive` (-ның/-дың/-тың…), `accusative` (-ны/-ды/-ты…), `instrumental` (-мен/-бен/-пен),
`plural` (-лар/-дар/-тар…).

## Как встроить в игру

1. В ARB плейсхолдер получает уже склонённое значение, аффикс из строки убирается:

   ```json
   "giftSentTo": "{recipient} жіберілді",
   "@giftSentTo": {
     "placeholders": {"recipient": {"type": "String", "description": "Имя в дательном падеже (kkInflect, KkCase.dative)"}}
   }
   ```

2. В коде склоняем только для казахского, остальные языки не меняются:

   ```dart
   final recipient = locale.languageCode == 'kk'
       ? kkInflect(name, KkCase.dative)
       : name;
   Text(l10n.giftSentTo(recipient));
   ```

Строки, которые `locqa` пометил как `suffix_harmony`, можно чинить так, без перефразирования.
Если код игры менять нельзя, остаётся вариант перефразирования, который предлагает `locqa`.

## Проверка

Логика — порт `locqa/lang/kk_runtime.py`. Обе версии сверяются на одних и тех же 343 примерах
(`test/vectors.json`: казахские и русские имена, числа, бренды, ники на латинице).

```bash
python scripts/gen_kk_affix_vectors.py   # из корня репозитория, после изменения правил
dart run test/parity_test.dart           # из этой папки
```

## Ограничения

- Английские слова читаются по написанию с одним исключением: немая `e` на конце (Google, Apple).
  Для редких брендов окончание может отличаться от привычного произношения.
- После мягкого знака (`Игорь`, `инвентарь`) гармония считается по последней гласной (`Игорьға`).
  Нормы здесь расходятся, вариант стоит подтвердить носителем.
