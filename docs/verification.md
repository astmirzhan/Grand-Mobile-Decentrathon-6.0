# Проверка проекта перед сдачей

Проверка выполнена 31 октября 2026 года. Это результаты конкретных прогонов, а не гарантия отсутствия любых ошибок перевода.

## Что проверено

- Установка обычного, не editable-пакета в отдельное чистое Python-окружение.
- Запуск установленного `locqa` вне репозитория на синтетических ARB.
- Полный офлайн-процесс в отдельной копии проекта с исходными данными: JSON/HTML-отчёт, CSV A/B/C, сборка HTML-страницы разметки.
- Воспроизведение сдачи из исходных CSV и четырёх текстовых подтверждений носителя, извлечённых из частного архива.
- Побайтное совпадение воспроизведённого исправленного ARB, метрик и подтверждений с текущей сдачей.
- Все 382 изменённых значения имеют человеческую проверку; ожидающих подтверждения нет.
- Офлайн-проверка исправленного ARB: 0 находок. Это не доказательство отсутствия всех смысловых ошибок.
- 133 автоматических теста Python; 343/343 общих вектора Dart/Python.
- Запуск узбекского бонусного скрипта и транслитерации, включая отчёт роста строк.
- Структурная проверка ARB, Flutter-генерация совместимой копии, целостность архивов и контрольных сумм.

## Исправления по результатам перепроверки

- Загрузчик разметки теперь использует общий ARB-парсер: UTF-8 BOM, метаданные и повторные ключи обрабатываются одинаково.
- Повторный ключ имеет одно эффективное место в порядке обхода; исходные пары сохраняются для записи и предупреждений.
- Некорректные JSON-корни и нестроковые ресурсы отклоняются вместо преобразования в текст перевода.
- Неверные явно указанные пути к исходнику, глоссарию и языкам-свидетелям вызывают ошибку вместо неполной проверки.
- `--no-llm` сохраняет приоритет при включённом `LOCQA_OFFLINE`.
- Транслитерация работает с компактными ARB и создаёт каталоги результатов.
- Сборка отклоняет повторные дополнительные исправления одного ключа.
- CI проверяет установленную команду из каталога вне репозитория.

## Границы проверки

Живой платный LLM-прогон не повторялся; LLM-ветки покрыты тестами с подставными ответами. Автоматический прогон CI на GitHub требует отправки коммита; локальные проверки не означают, что удалённый workflow уже выполнен. HTML-страница собиралась автоматически, но полный новый ручной проход по всем её карточкам не выполнялся.

Исходные игровые имена трёх ключей несовместимы со стандартным Flutter. В сдаче сохранены оригинальные имена и отдельно включены совместимые копии, карта переименований и оба журнала генерации. Прямая генерация исходного варианта по-прежнему не проходит; это оговорка к требованию ТЗ, а не скрытый успешный результат.

Скрытый тест организаторов недоступен. Транслитерация экспериментальная; узбекский бонус не заменяет полную лингвистическую проверку. Историческая стоимость LLM остаётся оценкой из лога, а не подтверждённым счётом провайдера.
